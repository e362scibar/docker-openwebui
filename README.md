# Open WebUI Docker Environment

A Docker Compose setup that provides an Open WebUI service on an internal network.
It integrates AI models on AWS Bedrock via LiteLLM and connects GitHub / GitLab MCP servers
to support AI agent operations.

## Services

| Service | Image | Port | Description |
| -------- | -------- | ------ | ---- |
| `open-webui` | `ghcr.io/open-webui/open-webui:v0.11.0` | `3000:8080` | Open WebUI frontend |
| `litellm` | `ghcr.io/berriai/litellm:v1.94.1` | `4000:4000` | Bedrock API proxy |
| `docling` | `ghcr.io/docling-project/docling-serve-cu130:v1.29.0` | — | Document processing service |
| `github-mcp` | `ghcr.io/github/github-mcp-server:v1.8.0` | `8082:8082` | GitHub MCP server (read-only) |
| `gitlab-mcp` | `gitlab/glab:latest` (custom) | `8083:8083` | GitLab MCP server (via glab-cli) |
| `gitlab-mcp-readonly` | Custom (FastAPI) | `8084:8084` | GitLab MCP read-only proxy |

## Setup

### 1. Environment Variables

Create a `.env` file with the required secrets:

```bash
AWS_API_KEY=<your-aws-bedrock-api-key>
WEBUI_SECRET_KEY=<random-secret-string>
GITHUB_PAT=<your-github-personal-access-token>
```

| Variable | Description |
| ---- | ---- |
| `AWS_API_KEY` | Bearer token for AWS Bedrock |
| `WEBUI_SECRET_KEY` | Session encryption key for Open WebUI |
| `GITHUB_PAT` | GitHub Personal Access Token (for MCP connection) |

### 2. GitLab MCP Initialization (First Time Only)

Configure GitLab connection details in `gitlab-mcp/glab-cli/config.yml`:

```yaml
# gitlab-mcp/glab-cli/config.yml example
gitlab:
  host: gitlab.example.com
  token: <your-gitlab-personal-access-token>
```

### 3. Build GitLab MCP Read-Only Proxy

The `gitlab-mcp-readonly` service uses `glab-openapi-readonly.json`, which is generated by
filtering endpoints from `glab-openapi.json`.

```bash
python3 filter-openapi.py
```

Edit `keep_paths` in `filter-openapi.py` to restrict which endpoints are exposed.

### 4. Start Services

```bash
docker compose up -d
```

### 5. Access Open WebUI

Open `http://<your-server-ip>:3000` in a browser.

## Directory Structure

```
.
├── docker-compose.yml          # Main configuration
├── litellm-config.yaml         # Bedrock model definitions
├── filter-openapi.py           # GitLab OpenAPI endpoint filter
├── data/                       # Open WebUI persistent data
├── uploads/                    # User-uploaded files
├── vector_db/                  # ChromaDB vector store
├── github-openwebui-mcp-app.txt # GitHub MCP App configuration
├── gitlab-mcp/                 # GitLab MCP (glab-cli)
│   ├── Dockerfile
│   └── glab-cli/config.yml
└── gitlab-mcp-readonly/        # GitLab MCP read-only proxy
    ├── Dockerfile
    ├── main.py
    └── glab-openapi-readonly.json
```

## Operational Notes

- **Data Persistence**: `data/` stores Open WebUI's database and model cache.
- **Vector Store**: `vector_db/` persists ChromaDB data.
- **Cache**: `data/cache/` accumulates embeddings, image generation, and speech synthesis caches.
- **GitHub MCP**: Runs in read-only mode (`--read-only` flag).
- **GitLab MCP Read-Only**: `gitlab-mcp-readonly` only allows GET/HEAD for `glab_api`;
  write operations are rejected with 403.

## Troubleshooting

| Issue | Solution |
| ---- | ------- |
| Models not selectable | Verify `.env` `AWS_API_KEY` is correct |
| GitLab MCP connection fails | Check host and token in `gitlab-mcp/glab-cli/config.yml` |
| GitHub MCP errors | Verify `GITHUB_PAT` has the `repo` scope |
